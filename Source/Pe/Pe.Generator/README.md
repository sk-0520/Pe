# ソースジェネレータ 共有処理

* ソースジェネレータで毎回同じようなことを書く場合の共通処理
* ソースジェネレータから参照するのではなく、ファイル自体をリンクして使用する
  * プロジェクト参照するとことごとく死ぬのです
  * 共有プロジェクトだと `dotnet sln add` 出来ないのでリンクです
* C#プロジェクトにしているのは編集とかを簡単にするため
  * こいつのテストだけでしかプロジェクトのコンパイルは行われない

## 生成コードのカバレッジ

* 通常のプロジェクトでは、生成したメンバーと属性型をカバレッジ集計から除外する。手書きの部分型は除外しない。
* `Pe.Generator.*.Test` では `GENERATOR_COVERAGE` を定義し、そのプロジェクト内に生成されたコードを集計する。
* 専用テストでは `generator-testconfig.json` を出力先にコピーし、Microsoft Testing Platform のカバレッジ収集でテストアセンブリも計測する。テストコードも集計対象に含まれる。
* この設定は生成コードを含むアセンブリのビルド時に決まるため、専用テストから通常のプロジェクトを参照しても、そのプロジェクトの生成コードは除外されたままになる。
